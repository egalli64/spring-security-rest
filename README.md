## 3.5 - OAuth2 Client

- OAuth2 Support
	- pom.xml: spring-boot-starter-oauth2-client dependency
	-application.properties: each client requires its own spring.security.oauth2.client.registration values
- AuthenticationSuccessHandler, used to convert the OAuth2 token in a JWT token
	- OAuth2AuthenticationSuccessHandler (new): access the OAuth2User generated by the external service
- Let the @EnableWebSecurity configuration class to take care of the details
	- SecurityConfig: uses the AuthenticationSuccessHandler
